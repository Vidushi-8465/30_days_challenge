#  Text Summarizer using LLM (Streamlit)

A **Streamlit-based AI application** that summarizes long text using a **Large Language Model (LLM) API**, allowing users to generate concise summaries with customizable length.

---

## 🔹 Approach Used

* 1. User input text is collected through a Streamlit interface.
* 2. A prompt is dynamically generated based on the desired summary length.
* 3. An LLM API is called to perform abstractive text summarization.
* 4. The generated summary is displayed in real time.

---

##  Features

* AI-powered text summarization
* Adjustable summary length
* Clean and responsive UI
* Single-file deployment
* API-based LLM integration

---

##  Tech Stack

* **Python**
* **Streamlit**
* **LLM API (OpenAI-compatible)**
* **Requests**

---

##  How to Run

```bash
pip install streamlit requests
streamlit run text_summarizer_streamlit.py
```

---

##  Conclusion

This project demonstrates the practical use of **LLMs for natural language processing**, combining prompt engineering with a user-friendly Streamlit interface for real-world text summarization tasks.
